# Contributing

Matchbox stays small. A match declares its name and `run` function; optional `validate` and `verify` functions enforce its contract. See [MATCH_SPEC.md](MATCH_SPEC.md).

Keep provider APIs, storage, UI, and Cloudflare bindings outside the framework core. Add a focused test for every behavior and failure case. Run `npm test` before proposing changes.

Do not claim a strike is a light. For consequential external actions, verify the real result.
